## Overview

Miracle Web Builder is a powerful, AI-assisted website creation platform that allows hospitality businesses to build and deploy professional websites without writing a single line of code.

## Features

- 🧩 **Drag-and-Drop Editor** — Visual page builder with pre-built hospitality blocks
- 🤖 **AI Content Generator** — Gemini writes page copy, generates SEO meta, creates image prompts
- 🎨 **Theme System** — Professional templates tailored for hotels, resorts, and restaurants
- 📱 **Mobile-First** — Responsive preview for desktop, tablet, and mobile
- 🔗 **Direct Publish** — One-click deployment to custom domains
- 📊 **Analytics** — Built-in visitor tracking and conversion metrics

## Tech Stack

| Layer | Tech |
|-------|------|
| Frontend | Next.js 16, TypeScript, Tailwind CSS v4 |
| AI | Google Gemini 2.0 Flash |
| Backend | FastAPI (Miracle OS Master) |
| Auth | JWT + role-based access |
